# Space Combat Simulator (Terminal Edition)

A retro-style terminal game built with Python and Curses.

## How to Run

1. Ensure you have Python 3 installed.
2. Clone the repo or navigate to this directory.
3. Run the game:
   ```bash
   python3 game.py
   ```

## Controls

- `W` / `A` / `S` / `D`: Move your starship.
- `Space` / `F`: Fire lasers.
- `Q`: Quit game.

## Features

- Procedural starfield animation.
- Enemy wave spawning.
- Score tracking and collision detection.
- Unicode/Emoji graphics for a modern terminal look.
